# Cloud-Native CI/CD Pipeline

## Overview
This project demonstrates a cloud-native CI/CD pipeline using modern DevOps tools. It highlights infrastructure automation, container orchestration, and deployment workflows.

## Tech Stack
- Terraform (Infrastructure as Code)
- Ansible (Configuration Management)
- Helm & Kubernetes (Deployment)
- GitHub Actions (CI/CD Automation)
- Prometheus & Grafana (Monitoring)
